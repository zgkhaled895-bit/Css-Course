• Grid :

- It is a powerful layout system that allows you to organize elements within the page in the form of rows and columns , in a flexible and easy way .

• Grid Container (The parent) :

  1. grid-template-columns :

    Determine number of the columns in the grid , Ex : grid-template-columns : 25% 75% , take values : px, %, auto, fr, and take functions : repeat( ), minmax( )
    you can use More than one value together , Ex : grid-template-columns : 100px 1fr

    2. - What is the difference between fr and auto ?
    → auto : It only takes the content
    → fr : It takes the content and the rest of the space .

    - What is repeat( ) ?
    → repeat( ) is a function used to repeat columns or rows without writing them many times , Syntax : gird-template-columns : repeat(number, value);

    - What is the different between auto-fill and auto-fit ?
    → auto fill keeps empty columns while auto-fit removes empty columns and stretch items .

    - When do you use auto-fill/auto-fit insted of a fixed number ?
    → You use them when the number of columns is not fixed .

  2. grid-template-rows :

    Specifies the height of each row in the grid , take values : px, %, auto, fr, and take functions : repeat( ), minmax( ), Ex : grid-template-rows : repeat(3,40px) ;.

  3. gap :

    Specifies Space between items , Syntax : gap : row-gap column-gap , Ex : gap : 10px 20px; and you can use row-gap only or column-gap only .

  4. justify-content :

    It works on an axis X , It Doesn't work with fraction , take values : start , end , center , space-between , space-around , space-evenly .

  5. align-content :

    It works on an axis Y , It Doesn't work with fraction , take values : start , end , center , space-between , space-around , space-evenly .

  6. gird-template-areas :

    Defines named areas in a Css Grid layout for easy placement of elements .

• Grid Items :

  1. grid-column :

    Specifies the beginning and end of the element in the grid depending on the lines, and it is a shorthand for grid-column-start and grid-column-end ,Syntax : gird-column : start/end ,
    Ex : grid-column : 1/3 ; Note : When you do not know the number of lines and want the element to take a full line, set the ending value to -1 .

  2. grid-row :

    The same principle as grid-column , but for lines .

  3. grid-area :

    Give a name to a grid element .
