Pseudo-Classes

Control elements based on their state and position

What is a Pseudo-Class?

A pseudo-class is a keyword added to element selectors that is used to specify a particular state of the element (e.g., when a user hovers over it, or when an input is focused).

Syntax

The syntax is straightforward: use a colon (:) after the selector, followed by the pseudo-class name.

selector:pseudo-class {
                 property: value;
            }

Types of Pseudo-Classes

1. User Interaction Instances

  1. :hover : Applied when the user hovers the mouse over the element.
  2. :active : Applied while the user clicks on the element.
  3. :focus : Applied when the element receives focus, such as clicking into an input box.

2. Link Statuses

  1. :link : To format links that the user has not yet visited.
  2. :visited : To format links that the user has previously visited.

3. Arrangement and Structure

  1. :first-child : Selects the first child element.
  2. :last-child : Selects the last child element.
  3. :nth-child(n) : Selects elements based on a specific formula or number (e.g., :nth-child(2) selects the second child).
