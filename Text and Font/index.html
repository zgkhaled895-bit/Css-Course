Text and Font :

Proparites :

1.Text :

• color: sets the text color , Ex: color: red;
• text-indent : add space at the beginning of a paragraph , Ex: text-indent: 20px;
• text-decoration : add decoration like underline,overline,or line-through, Ex: text-decoration: underline
• text-align : aligns the text horizontally(left,center,right,or justify), Ex: text-align: center
• text-shadow : add a shadow effect behind the text, Ex: text-shadow: 2px 2px 5px gray
• text-transform : Changes the case of the text, Ex: text-transform: uppercase
• text-rendaring : It controls in the way text is displayed in the browser in terms of clarity or speed of performance, Ex: text-rendaring : optimizeSpeed
• text-wrap : Specifies how text wraps at the end of a line, Ex: text-wrap: wrap
• line-height : Sets the space between lines of text, Ex: line-height: 20px
• letter-spacing : Adjust the space between letter, Ex: letter-spacing: 2px

2.Font :

• font-size : Sets the size of the text, Ex: font-size: 20px;
• font-weight : Sets the thickness of the text, Ex: font-weight: bold
• font-family : Specifies which font type is used to display the text, Ex: font-family: Arial, sans-serif;
• font-style : Defines the style of the text(normal,italic,or oblique), Ex: font-style: oblique
• font-variant : these property is used to make the lowercase letters appear as smaller uppercase letters, while the real uppercase letters remain larger, Ex: font-variant: small-caps
• font-display : Specifies what happens to the text while the font is loading from the internet , also is used inside @font-face in Css, Ex: font-display: swap
