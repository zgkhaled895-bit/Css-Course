• Css Units :

1. Absolute Units :

Px (Pixels) :

- A pixel is a single point on the screen

- cm\mm\in (centimeter\millimeter\inch):

- Real physical units are rarely used in web design .

Pt (Points) :

- A unit used in printing .

• What is the difference between pixel and point ?
- Pixels are used for digital display on screens and websites , while points are used for printing or PDF files .

2. Relative Units :

A. Font-Relative :

1. rem (Root EM) :

- It depends on the font size of the site's root element (<html>) , The default root font size in browsers is 16px , If the user changes the browser's default font size, all the 'rem' values ​​on your site will scale up or down in perfect proportion.

2. em :

- It depends on the font size of the direct parent element.

B. Viewport-Relative :

1. vw (Viewport Width) :

- A percentage of the entire screen width , This means that 1vw is equal to 1% of the screen width , If your screen width is 1000px , 1vw will equal 10px.

2. vh (Viewport Height) :

- A percentage of the entire screen length, 100vh means fill the entire length of the screen .

3. % (Percentage) :

- Depends on the direct parent element , This means that if the father has a width of 500px , and the son is given width: 50%; , the son will have a width of 250px.
