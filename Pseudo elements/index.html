Pseudo-Elements

What is a Pseduo elements ?

Pseudo-elements are used to target a specific part of an element's content and format it, or to create a new dummy element and add it before or after the main element's content without having to write it in HTML.

Syntax :

use a double colon (::) after the selector, followed by the pseudo-class name.

selector::pseudo-element {
                 property : value ;
            }

Types of pseudo-element :

1.Content generation elements :

- It is used to create completely new virtual elements on the page without writing them in HTML , examples :

  1. ::before : Creates a dummy element and places it just before the content of the original element , "content:" property must be used always with her .
  2. ::after : ::before : Creates a dummy element and places it just after the content of the original element , "content:" property must be used always with her .

2.Text formatting and typography elements :

- These elements are used to target very specific parts of text within paragraphs, and are very useful for professional magazine and blog designs , examples :

  1. ::first-letter : targets only the first character of the text displayed within the element .
  2. ::first-line : targets only the first line of text .

3.User interface and interaction elements :

- These elements control parts that appear only when the user interacts with the page or input fields , examples :

  1. ::placeholder : Used to format placeholder text inside input fields .
  2. ::selection : Targets the part of the text that the user selects and highlights with the mouse .

4.List and table elements :

- For example :

  1. ::marker : Targets the list tag (automatic dots for <ul> or numbers for <ol>).
