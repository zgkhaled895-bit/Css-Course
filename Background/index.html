Background :

• background color :

- the color that appears behind the content of an element on a webpage or design :

• background image :

- An image placed behind the content of an element, used as background insted of color :

• background size :

- Determines the size of the background image (take values : width height | width | auto | cover | contain) :

• background repeat :

- take values : repeat | no-repeat | repeat-x | repeat-y | space | round :

• background attachment :

- determines how the background image behaves when scrolling: it moves with the page , remains stationary , or moves within the element itself.

- take values : scroll | fixed | local .

• background position :

- sets the position of the background image , take values : left center | top left | 10px(horizontal) 20px(vertical) | 50% 50% (Percentages)

• background shorthand :

background : Color image repeat position/size , Ex : background : red url("image\pic.png") repeat center/cover
