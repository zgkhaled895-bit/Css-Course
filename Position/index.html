• Position :

- Defines how an element is placed on a webpage relative to its normal position, its parent, or the viewport.

• Position types :

1.Static (Default) :
- The element remains in its normal place :

2.Relative :
- the original location of the element remains empty.
- the element moves relative to its original position.(relative to himself)

3.Absolute :
- the original location of the element does not remain empty.
- the element moves relative to screen if the father does not have a position,Otherwise the element will move relative to the father .

4.Fixed :
- the original location of the element does not remain empty.
- the element moves relative to the screen

5.Sticky :
- the element becomes fixed during scrolling .
- the element remains within the father's boundaries even if we work scroll .
