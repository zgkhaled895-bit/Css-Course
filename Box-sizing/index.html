• Box-Sizing :

- Determines how the width and height of an element are calculated , and this is a very important point to avoid layout problems , it has two values :

  1. content-box :

    Width and height include only the content , padding and border are added outside → increase total size .

  2. border-box :

    Width and height include content + padding + border , Total size stays fixed → easier layout control .

- Why use it ?
→ It Prevent elements from "suddenly growing" because Padding or border .
