• Flexbox :

- A modern CSS layout module designed for building flexible and responsive interfaces.

1. The Flex Container (The Parent) :

- The first step in using Flexbox is defining a Flex Container, By applying display: flex; to an element, you instantly transform all children into "flexible items".

The most important characteristics of the container:

flex-direction : This property defines the Main Axis of the container, take values :

  • Row (Default): Items align horizontally (Left to Right).
  • Column: Items align vertically (Top to Bottom).

justify-content :Controls in distribution of the elements on the Main axis , take values :

  • Center : elements in the center.
  • Space-between :equal spaces between elements.
  • Space-around : spaces around and between items but not equal spaces.
  • Space-evenly : equal spaces between and around items.
  • Left .
  • Rigth .
  • flex-start (Default).
  • flex-end .

align-items :Controls in distribution of the elements on the Cross axis, take values :

  • center :elements in the center.
  • flex-start :This property takes care of edges , and different from basline , It takes all the elements and pastes their top edges to the beginning of the container (in the case of a row), For example, if you have a large box and a small box, the "vertexes" of the boxes will be equal at the top
  • flex-end .
  • stretch (Default):The elements expand to completely fill the container , If the length and width are not specified .
  • basline :This property takes care of content ,and it is different from flex-start. It aligns elements based on content (Text).

flex-wrap :

  • wrap : allows flex items to wrap onto multiple lines if they can't fit in a single line.
  • nowrap : prevents flex items from wrapping onto multiple lines, all items will be displayed in a single line.
  • wrap-reverse : allows flex items to wrap onto multiple lines , but in the opposite direction.

flex-flow : The two properties flex-direction and flex-wrap are used so often together that the shorthand property flex-flow was created to combine them .

2. Flex Items :

- After configure the container, you can control each individual element within it.

The most important characteristics of the items :

order :It determines the order of the element inside flex container , Zero is the default value , It takes positive and negative values.

flex-grow : Specifies how much the item expands to take up additional space, Zero is the default value :

  • 1 → take up additional space .
  • if you hane two elements the first element has flex-grow: 1 and the second has flex-grow: 2 , the second element take Double the space .

flex-shrink : Determines how much the item shrinks if there is not enough space , defult value is one .

flex-basis : Specifies the basic size of the element before expansion or contraction , It could be px,%,auto :

  • in case : flex-direction : row → flex-basis = width
  • in case : flex-direction : column → flex-basis = height

align-self : Controls in one element only and exceed align-items located on the container, take values : auto , flex-start , flex-end , center , stretch , basline .

Flex Shorthand :
flex : flex-grow flex-shrink flex-basis , Ex: flex : 1 1 200px;
